# 巡天智能体科学收益修正版 — 2026-10-05

基于朋友已合并的 team PR #2 和集中候选，针对用户上传后的 v1 回执修正策略。
朋友基线 main 为 `8792dd2fc15fdaacf131a47c17ddb32594f3e63a`。只交付一个通用版本，
不按卡名、固定月份或目标编号写策略。

将 ZIP 作为完整项目上传。包根目录含 `observer.project.json`，平台使用
`python:3.12-slim` 运行 `python3 -u agent.py`。只用标准库，无需 GPU。

平台沿用朋友原版的模型设置：`OPENAI_API_KEY` 或 `KIMI_API_KEY`，以及
`OPENAI_BASE_URL`、`OPENAI_MODEL`。未设置时保留朋友的 Kimi Coding 地址和
`k3` 默认模型。运行时需要 API key；不得写进文件。本包不含凭据、题目数据、
隐藏 truth、测试输入。

官方 science 取每个目标的有效单次曝光最高分。旧版在相近收益率时容易选择
短曝光，不能靠重复短曝光累加补齐。本版在收益率相差不超过 3% 时优先收益
更完整的单次曝光；视场召回同时考虑可实现收益与空间密度。

同一次观测的多根光纤反馈先聚合，再更新天气与故障证据，避免 100 根光纤
被误当成 100 次独立天气观测。program-band 判断与含仪器效率的曝光质量
分开估计，效率从公开反馈更新。上报/失效回滚后清除过期推断；零分方向的
经验屏蔽会衰减，不会永久封锁。

每个活跃请求优先召回至少一个可见且预计能达到门槛的目标，在光纤和指向
截断时保留它。请求奖励仍按完整窗口与实际剩余数量判断，保留有限两步规划，
包括 CPU 快速档。第二步临时扣除第一步预计完成的请求目标，避免重复选择；
真实账本仍只认平台回执。保留 REQUIRED 未来机会、均匀性、独立 science/completion
账本及失效回滚。支持 9、16、25、100 等合法平方光纤网格。

冻结初始启发式：质量 20/50/80 分位数及 0.2/0.6/0.2 情景权重；未知未来
天气固定先验 0.65；整季最多 28 个规划问题、64 次 HTTP 尝试；单次超时 8 秒，
每个问题总预算 18 秒，保留末尾 300 秒墙钟。以上均为工程近似，未通过正式
分数调参。官网回执只有六位小数 score，不能始终唯一反推 completion factor，
因此账本保存保守下界；两步规划只执行第一步，实际回执后重规划。

验证范围：合成逻辑回归、四种公开几何的协议与反馈/回滚、localhost 模型模拟、
小量公开输入 CPU 诊断，以及用户 v1 公开反馈的抽样回放。测试与回放材料在
ZIP 外。回放只验证策略与反馈处理，没有生成新正式成绩，也没有读取 truth。
真实模型可用性、平台 CPU 用量、线上提升和榜单排名待平台实测。
