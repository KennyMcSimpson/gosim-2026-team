# v2-pi-fixed：恢复 v2 行为的修复候选

基于 Kenny 指定原 v2，team 提交 `1589f104cf2bda6dc5bd2df7d9c008caed32ce03`。
默认 `AGENT_MODEL_BACKEND=pi-fixed` 恢复原 v2 的异步公告与反馈两个模型角色，
模型通信使用 Pi 1.0.3 的单轮工具接口。Python 保留原数值搜索、几何、状态与提交。
默认关闭 pi-pro 的同步动作替换及候选额外收集。

反馈建议按请求身份、季度、作废状态、命中率分档和有限质量变化复核新鲜度，
请求内完成数量变化不再自动作废全局建议。两个角色独立分配每季总计 28 问额度，
避免公告占满额度。实际采用的 priority/risk/方向写入平台可导出的 stderr。
故障确认允许模型否决一次；冷却后重新累积完整多晚证据时不再允许永久否决。
这是报告行为变化，真实模型误报率尚未验证；`v2` 对照保留原顾问新鲜度、额度和否决语义。

`v2` 使用原 HTTP 客户端；`disabled` 不调用模型；`pi-review` 显式开启实验候选评审。
评审拒绝估计科学收益率、总收益率、REQUIRED 完成数/最后机会数、请求奖励或有效概率
低于原方案的候选，候选与取舍均写入 stderr。数值约束仍不保证最终得分无损。

网页完整项目入口上传 ZIP。模型变量沿用 `OPENAI_BASE_URL`、`OPENAI_MODEL`
和运行时 `OPENAI_API_KEY` / `KIMI_API_KEY`，凭据不放入 ZIP。
平台构建下载校验固定 Node 22.20.0 Linux x86_64，并复核内置 Pi bundle。
打包命令：`python3 pack_agent.py`。

本包是回归修复候选；工程验证与模拟 provider 不能证明线上提分。
失败的 v2-pi、v2-pi-pro 原包保持不变，具体分项和失败边界见仓库失败说明。
